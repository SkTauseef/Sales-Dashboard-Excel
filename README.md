# 📊 Sales Dashboard (Excel Project)

## 📌 Project Overview

This project focuses on analyzing sales data and building an interactive dashboard using Microsoft Excel.

The objective is to understand sales performance across categories, regions, and time, and present insights through a clean and interactive dashboard.

---

## 🛠 Tools Used

* Microsoft Excel

  * Pivot Tables
  * Pivot Charts
  * Slicers
  * Dashboard Design

---

## 📂 Dataset

The dataset contains sales records with the following fields:

* Order Date
* Category
* Region
* Sales

---

## 🔍 Analysis Performed

### 📊 1. Category-wise Analysis

* Technology is the highest-performing category
* Followed by Furniture and Office Supplies

---

### 🌍 2. Region-wise Analysis

* West region generates the highest sales
* South region contributes the least

---

### 📈 3. Monthly Sales Trend

* Sales fluctuate over time
* Certain months show noticeable spikes

---

## 📊 Dashboard Features

* KPI Cards:

  * Total Sales
  * Total Orders
  * Average Sales

* Interactive Filters (Slicers):

  * Category
  * Region
  * Year

* Visualizations:

  * Sales by Category (Bar Chart)
  * Sales by Region (Bar Chart)
  * Monthly Sales Trend (Line Chart)

---

## 🧠 Key Insights

* Technology category drives the most revenue
* West region shows strong sales performance
* Sales trends are inconsistent, indicating fluctuating demand
* Some months show higher sales, suggesting possible seasonality
